# Portfólio

Portfólio pessoal de Walkyria Tonolli, desenvolvido e aprimorado conforme o avanço dos meus estudos em desenvolvimento web.

O projeto começou junto com minhas primeiras as aulas de programação da Alura e vem sendo evoluído durante a graduação em Análise e Desenvolvimento de Sistemas (Senac) e o curso Full-Stack Engineer (Codecademy).

## Páginas

- `index.html`: página inicial com apresentação e links para as redes sociais.
- `about.html`: sobre mim.
- `resume.html`: currículo.

## O que apliquei neste projeto

- **HTML e CSS:** ambientes de desenvolvimento, estrutura de arquivos e tags.
- **HTML e CSS:** classes, posicionamento e Flexbox.
- **CSS responsivo:** layout adaptado para tablet e celular com media queries (`media-tablet.css` e `media-mobile.css`).
- **JavaScript:** componentes reutilizáveis com Web Components (`customElements`), como cabeçalho, rodapé, imagem de perfil e links de redes sociais, evitando repetição de código entre as páginas.
- **JavaScript:** geração dinâmica dos links das redes sociais a partir de uma lista (`map` e template literals) e destaque automático do item ativo no menu de navegação.

## Estrutura

```

├── Styles/    # CSS global, páginas e responsividade
```
